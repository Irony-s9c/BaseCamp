# BaseCamp

Minecraft サーバーの作成・起動・外部公開・バックアップを、ひとつの画面で行える Windows 用ソフトです。

## 概要

BaseCamp は、Minecraft の Java 版サーバーを自分のパソコンで動かすためのソフトです。
サーバーの種類とバージョンを選ぶだけで、サーバー本体と必要な Java を自動でダウンロードして準備します。
ルーターのポート開放をしなくても、playit.gg というサービスを使って友人がサーバーに参加できるようにします。

## 動作環境

- Windows 11 / Windows 10（64 ビット）
- Microsoft Edge WebView2 ランタイム（Windows 11 には標準で入っています）
- インターネット接続（サーバー本体・Java・MOD のダウンロードと外部公開に使います）
- メモリは、参加人数や MOD の量に応じて 4GB 以上の空きがあることをおすすめします

## ダウンロード

[Releases](https://github.com/Irony-s9c/BaseCamp/releases/latest) から `BaseCamp-<バージョン>-portable.exe` をダウンロードしてください。インストールは不要で、好きなフォルダに置いて使えます。

インストーラー版（setup.exe）は v0.14.2 から配布していません。v0.14.1 までのインストーラー版をお使いの方は、ポータブル版に切り替えてください。

「更新履歴のみ」と書かれたバージョンは開発途中のもので、ダウンロードできるファイルはありません。

## インストールと起動

1. `F:\BaseCamp\` のような、自分で管理しやすいフォルダを作ります。
2. ダウンロードした `BaseCamp-<バージョン>-portable.exe` をそのフォルダに置き、ダブルクリックで起動します。
3. 同じフォルダに `BaseCampData` というフォルダが作られ、サーバーやバックアップはすべてここに保存されます。

## 使い方

1. 左のメニューの「＋」または「新しいサーバー」を押します。
2. 種類（Vanilla / Paper / Fabric / Forge / NeoForge）、Minecraft のバージョン、想定する参加人数を選びます。
3. Minecraft の利用規約（EULA）に同意して「作成してインストール」を押すと、準備が始まります。
4. 準備が終わったら「起動」を押します。コンソールに「サーバーの起動が完了しました」と表示されれば完了です。
5. 友人に参加してもらう場合は、設定の「外部公開」で「playit.gg と連携」を押し、ブラウザで承認します。
   その後、playit.gg のサイトで「Minecraft Java」のトンネルを作成すると、サーバー画面に接続用のアドレスが表示されます。

## 主な機能

- サーバーの作成：Vanilla / Paper / Fabric / Forge / NeoForge に対応しています。Paper はビルド番号も選べます。
- Java の自動準備：Minecraft のバージョンに合った Java（Eclipse Temurin）を自動でダウンロードします。パソコンの環境設定は変更しません。
- バージョンの変更：作成済みのサーバーも、あとから Minecraft のバージョンを変更できます。変更前には自動でバックアップを作成します。
- メモリの自動設定：パソコンのメモリ量と想定する参加人数から、サーバーに割り当てるメモリ量を自動で決めます。手動でも変更できます。
- 外部公開：playit.gg を使い、ポート開放なしで外部から参加できるようにします。必要なプログラムは自動でインストールします。
- MOD とプラグイン：Modrinth から、サーバーのバージョンに対応するものだけを検索して導入できます。必要な前提 MOD も自動で導入します。
- バックアップ：1 日 2 回（定期再起動の前と指定した時刻）自動で作成し、最新 14 件を残します。ボタンひとつで復元できます。
- 定期再起動：指定した時刻にサーバーを再起動します。前もって「5 分前 → 1 分前 → 30 秒前 → 10 秒前 → 3 → 2 → 1 → 再起動」のようなカウントダウンを、ゲーム内に文字と効果音でお知らせします。お知らせのタイミングや文面は自由に変えられ、ドラッグで並べ替えもできます。
- ゲーム内のお知らせ：お知らせの文面は、太字・色・グラデーションなどを付けて編集できます。効果音はゲームにあるすべての音から試聴して選べ、音符ブロックの音は音階も指定できます。
- Discord 連携：Webhook または Bot で、サーバーのログや起動・停止のお知らせを送ります。ログは、管理者向けのコンソールログ（アプリと同じ色分け）と、チャットや参加・退出などだけをまとめた一般向けログを、別々のチャンネルに送れます。Bot は Minecraft サーバーの起動中だけオンラインになり、ステータスにオンライン人数を表示します。Discord から /mc コマンドでサーバーのコマンドも実行できます。
- ダッシュボード：サーバーの処理速度（TPS・MSPT）とメモリ使用量を 10 秒ごとにグラフで表示します。
- プレイヤー管理：ログイン中のプレイヤーを顔のアイコン付きで一覧表示し、OP の付与・解除、持ち物の消去、キック、BAN をボタンで行えます。BAN したプレイヤーの一覧も表示し、サーバーを止めていても解除できます。
- ゲーム内の TPS 表示：サーバーの処理速度（TPS・MSPT）を、TAB キーで開くプレイヤー一覧の上や下、ボスバー、アクションバーに表示します。表示する位置や文面、色は自由に変えられます（Paper はすべての位置、その他はボスバーのみ）。
- 予約タスク：曜日と時刻、または一定の間隔を決めて、天候の変更やアイテムの配布、お知らせなどのコマンドを自動で実行します。
- 参加者用 MOD パック：サーバーにだけ必要な MOD を自動で外し、参加する人に必要な MOD と設定ファイルを、配布用の ZIP または Modrinth App などで読み込める形式（.mrpack）にまとめます（Fabric / Forge / NeoForge）。
- ワールドの修復：サーバーが落ちたときにクラッシュレポートを調べ、原因と思われる壊れたチャンクを知らせます。ワールド全体を巻き戻さずに、そのチャンクだけを作り直せます。
- 統合版からの参加：GeyserMC をボタンひとつで導入でき、playit.gg の統合版トンネルに合わせてポートを自動で設定します（Paper / Fabric / NeoForge）。
- サーバー設定：難易度やゲームモードなど主な設定を、説明付きの画面で変更できます。プラグインや MOD の設定ファイルも、スイッチや数値の入力欄で変更できます。
- 自動アップデート：起動時に新しいバージョンがあれば自動で更新します（設定で止められます）。

## データの保存場所

サーバー、バックアップ、Java などは、`BaseCamp-<バージョン>-portable.exe` と同じフォルダの `BaseCampData` に保存します。
v0.14.1 までのインストーラー版のデータは `%APPDATA%\com.ironys9c.basecamp` にあります。

playit.gg の Secret Key、Discord の Webhook URL と Bot のトークンは、ファイルではなく Windows の資格情報マネージャーに保存します。

## 注意事項

- 初めて起動するときに、Windows の SmartScreen が「Windows によって PC が保護されました」と表示することがあります。
  これはソフトに電子署名がないために表示されるものです。「詳細情報」を押してから「実行」を押すと起動できます。
- 同時に起動できるサーバーは 1 つです。
- 外部公開には playit.gg のアカウント（無料で作成できます）が必要です。
- Discord の Bot は、招待するときに「bot」と「applications.commands」の権限を付けてください。/mc コマンドで操作できます。チャンネルへの普通の発言もコマンドとして受け付けるには、Discord Developer Portal で「MESSAGE CONTENT INTENT」を有効にしてください。
- 統合版から参加するには、playit.gg のサイトで「Minecraft Bedrock」のトンネルも作成してください。
- TPS の表示は、Vanilla と Fabric では Minecraft 1.20.3 以降で使えます。
- ゲーム内の TPS 表示は、設定の「TPS 表示」で「表示する」をオンにすると使えます（初期状態はオフです）。Paper では、オンにしたあと最初の 1 回だけサーバーの再起動が必要です。
- ワールドの修復で削除したチャンクは新しく作り直されるため、そこにあった建物や持ち物は失われます。修復はサーバーを停止してから行ってください。
- 参加者用 MOD パックで、対応環境を判定できなかった MOD は同梱しています。必要に応じて外してください。
- Minecraft のバージョンを古いものに戻すと、ワールドが正しく読み込めなくなることがあります。戻す場合は、バックアップからの復元もご検討ください。
- ウィンドウの「×」を押すと、サーバーを安全に停止してから終了します。終了まで少し時間がかかることがあります。

## アンインストール

- ソフトを置いたフォルダごと削除してください。
- v0.14.1 までのインストーラー版：Windows の「設定」→「アプリ」→「インストールされているアプリ」から BaseCamp をアンインストールしてください。サーバーのデータは `%APPDATA%\com.ironys9c.basecamp` に残るため、不要であれば削除してください。
- 保存したキーやトークンを消す場合は、Windows の「資格情報マネージャー」で「BaseCamp」の項目を削除してください。

## 更新履歴

### v0.14.2（2026-10-06）

- 再起動前のお知らせやバックアップのたびに、OP の権限を持つプレイヤーのチャットに、コマンドの実行結果が大量に表示されていた問題を修正しました。Paper では表示されなくなり、その他のサーバーでも大きく減ります。BaseCamp のコンソールには、何を送ったかが 1 行で残ります。
- インストーラー版（setup.exe）の配布を終了し、ポータブル版のみの配布にしました。

### v0.14.1（2026-10-05）

- Minecraft 26.x 以降で作ったワールドで、ワールドの修復が「データが見つかりません」となり使えなかった問題を修正しました。
- TPS 表示を Paper で初めて使うときは、サーバーの再起動が 1 回必要であることを設定画面に表示するようにしました。

### v0.14.0（2026-10-05）

- サーバーの処理速度（TPS・MSPT）を、ゲーム内の TAB リストやボスバーに表示できるようにしました。
- BAN したプレイヤーの一覧を表示し、解除できるようにしました。
- チャットや参加・退出だけをまとめた「一般向けログ」を追加しました。アプリと Discord の両方で使えます。
- Discord に送るコンソールログに、アプリと同じ色を付けるようにしました。
- Discord Bot がオフラインのままになり、チャンネルからのコマンドが届かないことがある問題を修正しました。/mc コマンドでも操作できます。
- 再起動のカウントダウンを、タイトルとチャットの両方に表示できるようにしました。

### v0.13.0（2026-10-05）

- 再起動のカウントダウンで、ステップを左端の持ち手のドラッグで並べ替えられるようにしました（キーボードの ↑↓ でも移動できます）。
- 「ステップを追加」を押しても、追加されたように見えなかった問題を修正しました。

### v0.12.0（2026-10-05）

- 効果音に音符ブロックの音を選んだとき、鍵盤から音階（ファ#3〜ファ#5）を選べるようにしました。ゲーム内の音符ブロックと同じ高さで鳴ります。

### v0.11.0（2026-10-05）

- 再起動前のお知らせを、カウントダウンとして自由に組めるようにしました。「何分前」「何秒前」「3・2・1」など、タイミング・文面・効果音をそれぞれ設定できます。
- 効果音の試聴を、ゲーム内と同じ音の高さと音量で再生するようにしました。
- 設定ファイルの画面を広く使えるようにし、ウィンドウを大きくしなくても全体が見えるようにしました。長い行の折り返しも切り替えられます。

### v0.10.0（2026-10-04）

- 参加者用の MOD パックを作る機能を追加しました。サーバー専用の MOD は自動で外し、ZIP または .mrpack で出力します。
- サーバーが落ちたときに、原因と思われる壊れたチャンクを知らせるようにしました。
- 壊れたチャンクだけを削除して作り直す「ワールドの修復」を追加しました。修復前のファイルは自動で保存します。

### v0.9.0（2026-10-04）

- ダッシュボードを追加しました。TPS・MSPT・メモリ使用量をグラフで確認できます。確認のためにソフトが送るコマンドの結果は、コンソールに表示しません。
- ログイン中のプレイヤーを顔のアイコン付きで表示し、OP の付与・解除、持ち物の消去、キック、BAN をボタンで行えるようにしました。
- 曜日と時刻、または一定の間隔でコマンドを自動実行する「予約タスク」を追加しました。
- 設定ファイルを、スイッチや数値の入力欄で変更できる「かんたん編集」を追加しました。YAML と TOML のコメントはそのまま残ります。
- GeyserMC を導入すると、playit.gg の統合版トンネルに合わせてポートを自動で設定するようにしました。

### v0.8.0（2026-10-04）

最初の配布版です。

- Paper のビルド番号を指定できるようにしました。
- 作成済みのサーバーの Minecraft バージョンを変更できるようにしました。
- 「playit.gg と連携」ボタンで、外部公開の準備をブラウザでの承認だけで行えるようにしました。
- playit.gg のプログラムを、ソフトの起動時に自動でインストールするようにしました。

これより前のバージョンは開発途中のため配布していません。各バージョンの内容は [Releases](https://github.com/Irony-s9c/BaseCamp/releases) で確認できます。
